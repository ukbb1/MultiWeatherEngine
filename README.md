# 🌪️ MultiWeatherEngine 多天气系统引擎

Spaceflight Simulator (SFS) 的气象模组——把真实台风、雷暴搬进你的太阳系。

## ✨ 特性

- **6 类天气系统**：台风 / 单体雷暴 / 多单体 / 超级单体 / 飑线 / 中尺度对流系统（MCS），可同时存在
- **真实尺度与风力**：尺寸 = 现实 ×30%，风力分级对齐中国标准（TD 12.4 → 超强台风 57.1 m/s），7/10/12 级风圈保底
- **完整生命周期**：自然生成 → 1-2 分钟发展成型 → 成熟（自然升级强度档）→ 消散；可合并（大吞小、双台风重组）、可类型转变（单体→多单体→超级单体→MCS）
- **附属现象**：龙卷（多实例、随机落点、防重叠、同类合并）、下击暴流，强度随母体系统
- **真实风场**：眼壁风峰、风眼平静、湍流阵风、突发大风、风暴移动风，全部限风暴内部
- **降雨系统**：密度 ×3、随风倾斜（8 级锁 85°）、视距裁剪、只渲染最近系统
- **性能优化**：只对正在影响飞船的风暴实时更新粒子，远处风暴冻结省 CPU
- **环境氛围**：云中变暗偏黄、台风风眼放晴、屏幕抖动、闪电、生成/转变粒子过渡动画

## 📥 安装

1. 下载 Release 中的 `MultiWeatherEngine.dll`
2. 放入 SFS 的 `Mods/MultiWeatherEngine/` 目录（没有就新建）
3. 启动游戏，进入有大气层的星球，按 **F6** 打开气象菜单

## 🎮 热键

| 键 | 功能 |
|---|---|
| F6 | 气象菜单（召唤/添加附属现象） |
| F7 | 解散选中的系统（Shift+F7 隐藏 HUD） |
| F8 | 循环切换强度（平滑过渡） |
| F9 | 活跃系统面板 展开/收起 |

调试（不进键位提示）：F2 切风区半区 · F3/F4 移动风区 · F5 步进 · Shift+F2 区域黑框

## 📁 目录结构

```
Mods/MultiWeatherEngine/
└── MultiWeatherEngine.dll
```

## 🛠️ 从源码构建

需要 .NET SDK + SFS 游戏程序集引用（csproj 内已配置 HintPath），`dotnet build -c Release`。

本模组由 AI 辅助设计制作，风场/尺度/演化参数基于真实气象数据调研。
