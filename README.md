# MultiWeatherEngine 多天气系统引擎

Spaceflight Simulator (SFS) 的气象模组

## 特性

- **6 类天气系统**：台风 / 单体雷暴 / 多单体 / 超级单体 / 飑线 / 中尺度对流系统（MCS），可同时存在
- **完整生命周期**：自然生成 → 1-2 分钟发展成型 → 成熟（自然升级强度档）→ 消散；可合并（大吞小、双台风重组）、可类型转变（单体→多单体→超级单体→MCS）
- **附属现象**：龙卷、下击暴流，雨，风，强度随母体系统
- **真实风场**：眼壁风峰、风眼平静、湍流阵风、突发大风、风暴移动风
- **环境氛围**：云中变暗偏黄、台风风眼放晴、屏幕抖动、闪电


## 热键

| 键 | 功能 |
|---|---|
| F6 | 气象菜单（召唤/添加附属现象） |
| F7 | 解散选中的系统（Shift+F7 隐藏 HUD） |
| F8 | 循环切换强度（平滑过渡） |
| F9 | 活跃系统面板 展开/收起 |
